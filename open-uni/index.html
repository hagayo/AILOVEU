הכשרה מעשית למפתחי AI

המסלול מתוכנן כדי לקחת מפתחים מהבנה תכנותית ועד בניית מערכת GenAI עובדת ופריסה לענן.

מה לומדים בפועל?

בונים שירותי Backend ב-FastAPI, מתכננים חוזי API, משלבים מודלי שפה, ומפתחים סוכנים אוטונומיים שמפעילים כלים וממשקים חיצוניים.

לצפייה בתכנית דוגמת CRUD עם FastAPI מנגנון ReAct RAG

1) ארכיטקטורה

הפרדה בין צד לקוח וצד שרת, מחזור בקשה-תגובה, שכבות מערכת, ומתי מחלקים למיקרו-שירותים.

כניסה לעמוד

2) APIs ו-REST

HTTP, משאבים, CRUD, סטטוסים, אימות והרשאות, גרסאות, ו-Design שמחזיק פרודקשן.

כניסה לעמוד

3) סוכנים + RAG

Agentic Loop, Tool Calling, זיכרון ומצב, ותבנית ReAct. בנוסף, RAG להזרקת ידע ארגוני מבוקר.

ReAct | RAG

איך להשתמש באתר הזה כמדריך לימודי?

כל עמוד בנוי כמיני-פרק אקדמי: הסבר, דיאגרמה, דוגמאות, וקטע קוד. מומלץ לעבור לפי הסדר:

  1. ארכיטקטורה - קודם מבינים "איפה הקוד רץ".
  2. REST API - לומדים "איך מערכות מדברות".
  3. FastAPI CRUD - מקודדים בפועל.
  4. ReAct - הופכים את הכל לסוכן שמבצע משימות.
