01

מה בונים?

פרויקט Python קטן שמשתמש ב-requests וב-httpx, עם בדיקות אוטומטיות וזרימת עבודה מקצועית.

02

למי זה מתאים?

למתחילים שרוצים להבין איך עובדים נכון עם קוד, גרסאות, GitHub ואוטומציות בסיסיות.

03

מה הסוף?

Repository מסודר ב-GitHub שמריץ pytest ו-pylint אוטומטית בכל העלאה.
