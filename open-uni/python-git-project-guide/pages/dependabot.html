הוספת Dependabot

כל שלב כתוב בסדר ביצוע ברור, עם פקודות מוכנות להעתקה ודגשים למניעת טעויות.

1. התקנה2. פרויקט ראשון3. gitignore ו-README4. קוד ובדיקות5. שדרוג האפליקציה6. שכבת API7. CLI ושמירת JSON8. בדיקות המשך9. GitHub Actions6. Dependabotפקודות בסיסיות

.github/dependabot.yml

version: 2

updates:
  - package-ecosystem: "pip"
    directory: "/"
    schedule:
      interval: "weekly"

  - package-ecosystem: "github-actions"
    directory: "/"
    schedule:
      interval: "weekly"

Dependabot בודק עדכונים ל-requirements.txt וגם ל-GitHub Actions, ויוצר Pull Request כשיש עדכון.

Commit והעלאה

git add .
git commit -m "Add Dependabot configuration"
git push
