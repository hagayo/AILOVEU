מה השדרוג הבא?

בשלב הראשון בנינו קובץ Python פשוט. עכשיו נעלה רמה ונבנה אפליקציה קטנה יותר מסודרת: שכבת API, שכבת CLI, שמירת תוצאה לקובץ JSON, טיפול בשגיאות ובדיקות טובות יותר.

המטרה: ללמד את הסטודנטים שהקוד לא חייב להיות גדול כדי להיות מקצועי. מספיק להפריד אחריות ולכתוב בדיקות.

מבנה הקבצים החדש

python-git-first-project/
├── src/
│   ├── __init__.py
│   ├── github_client.py
│   ├── github_report.py
│   └── app.py
├── tests/
│   ├── __init__.py
│   ├── test_github_client.py
│   └── test_github_report.py
├── reports/
│   └── .gitkeep
├── requirements.txt
└── README.md

פקודות הכנה

mkdir -p reports
touch src/__init__.py tests/__init__.py reports/.gitkeep
touch src/github_report.py src/app.py tests/test_github_report.py

תיקיית reports תשמור קבצי JSON שנוצרים בהרצה. הקובץ .gitkeep מאפשר להעלות תיקייה ריקה ל-Git.

סדר העבודה הנכון

  1. יוצרים קבצים חדשים.
  2. כותבים שכבת קוד אחת בכל פעם.
  3. מריצים את הקוד ידנית.
  4. כותבים בדיקות.
  5. מריצים pytest ו-pylint.
  6. עושים Commit קטן וברור.
git status
git add .
git commit -m "Upgrade app structure with CLI and reports"
