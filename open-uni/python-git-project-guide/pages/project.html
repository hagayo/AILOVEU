מדריך Git למתחילים

פתיחת תיקייה ופרויקט Python ראשון

כל שלב כתוב בסדר ביצוע ברור, עם פקודות מוכנות להעתקה ודגשים למניעת טעויות.

1. התקנה2. פרויקט ראשון3. gitignore ו-README4. קוד ובדיקות5. שדרוג האפליקציה6. שכבת API7. CLI ושמירת JSON8. בדיקות המשך9. GitHub Actions6. Dependabotפקודות בסיסיות

1. יצירת תיקיית הפרויקט

cd ~/Desktop
mkdir python-git-first-project
cd python-git-first-project
code .

2. יצירת סביבת עבודה

python -m venv .venv
source .venv/Scripts/activate
python --version
pip --version
ב-macOS/Linux: מפעילים עם source .venv/bin/activate

3. התקנת ספריות

pip install requests httpx pytest pylint
pip freeze > requirements.txt

4. מבנה תיקיות

python-git-first-project/
├── .github/
│   ├── workflows/
│   │   └── python-ci.yml
│   └── dependabot.yml
├── src/
│   └── github_client.py
├── tests/
│   └── test_github_client.py
├── .gitignore
├── README.md
└── requirements.txt
