💻 צד לקוח (Client) וצד שרת (Server)

אתרי אינטרנט מורכבים משני חלקים עיקריים שעובדים ביחד:

🖥️ צד לקוח (Client Side)

מה זה? זה הקוד שרץ בדפדפן שלך (Chrome, Firefox וכו')

טכנולוגיות:

  • HTML - המבנה של הדף
  • CSS - העיצוב והצבעים
  • JavaScript - האינטראקציות והאנימציות

דוגמה: כשאתה לוחץ על כפתור ורואה אנימציה - זה צד לקוח!

🖧 צד שרת (Server Side)

מה זה? זה הקוד שרץ על מחשב מרוחק (שרת) ומעבד בקשות

טכנולוגיות:

  • Python - שפת תכנות פופולרית
  • Node.js - JavaScript בצד שרת
  • Java, C#, PHP - עוד שפות

דוגמה: כשאתה מתחבר לאתר ובודק סיסמה - זה צד שרת!

המשתמש שולח בקשה ← השרת מעבד ← השרת מחזיר תשובה ← הדפדפן מציג

תהליך התקשורת בפירוט

  1. המשתמש מבקש מידע - לוחץ על קישור או כפתור בדפדפן
  2. הדפדפן שולח בקשה - בקשת HTTP עוברת דרך האינטרנט לשרת
  3. השרת מעבד את הבקשה - הקוד בצד שרת רץ ומביא מידע ממסד נתונים
  4. השרת מחזיר תשובה - השרת שולח את המידע בחזרה כ-HTML/JSON
  5. הדפדפן מציג את התוצאה - הדפדפן מעבד ומציג את המידע למשתמש

🔌 API - ממשק תכנות יישומים

מה זה API?

API (Application Programming Interface) הוא כמו תפריט במסעדה - הוא אומר לך מה אתה יכול להזמין וכיצד.

📖 דוגמה מהחיים

תחשוב על מסעדה:

  • המלצר = ה-API
  • אתה (הלקוח) = האפליקציה שלך
  • המטבח = השרת

אתה לא נכנס למטבח ישירות - אתה מדבר עם המלצר, והוא מביא לך את מה שהזמנת!

סוגי APIs נפוצים

REST API

הסוג הנפוץ ביותר. משתמש בפעולות HTTP פשוטות:

  • GET - קבל מידע
  • POST - צור משהו חדש
  • PUT - עדכן משהו קיים
  • DELETE - מחק משהו

GraphQL

טכנולוגיה חדשה יותר מ-Facebook. מאפשרת לך לבקש בדיוק את המידע שאתה צריך.

WebSocket

תקשורת דו-כיוונית בזמן אמת. מושלם לצ'אטים ומשחקים.

// דוגמה לקריאת API עם JavaScript fetch('https://api.example.com/users') .then(response => response.json()) .then(data => { console.log('קיבלתי את המידע:', data); }) .catch(error => { console.error('שגיאה:', error); });

מערכות שונות יכולות לדבר אחת עם השנייה - Facebook עם Instagram, למשל.

☁️ מחשוב ענן (Cloud Computing)

מה זה "ענן"?

במקום לקנות ולתחזק שרתים בעצמך, אתה שוכר כוח מחשוב מחברות גדולות דרך האינטרנט.

🏠 בעבר (On-Premise)

  • קנית שרתים יקרים
  • שמת אותם במשרד
  • שילמת על חשמל וקירור
  • שכרת אנשי IT לתחזוקה

☁️ היום (Cloud)

  • שוכר שרתים וירטואליים לפי שעה
  • משלם רק על מה שאתה משתמש
  • מגדיל או מקטין בלחיצת כפתור
  • החברה מטפלת בתחזוקה

סוגי שירותי ענן

IaaS

Infrastructure as a Service

שוכר שרתים וירטואליים, אחסון, רשת.

דוגמה: EC2 של AWS - אתה מקבל שרת ריק ומתקין עליו מה שאתה רוצה

PaaS

Platform as a Service

פלטפורמה מוכנה לפיתוח.

דוגמה: Heroku, Google App Engine - פשוט מעלה קוד והם מטפלים בשאר

SaaS

Software as a Service

תוכנה מוכנה לשימוש.

דוגמה: Gmail, Salesforce, Dropbox - פשוט נכנס ומשתמש

למה Python?

Python היא שפת תכנות פופולרית וקלה ללמידה, מושלמת למתחילים ומקצוענים כאחד.

✨ קלה לקריאה

🚀 רב-תכליתית

אתרים, מדע הנתונים, אוטומציה, AI ועוד

📚 קהילה ענקית

מיליוני מפתחים וספריות לכל צורך

דוגמאות קוד בסיסיות

# משתנים והדפסה name = "דני" age = 25 print(f"שלום, קוראים לי {name} ואני בן {age}") # פונקציה פשוטה def calculate_sum(a, b): return a + b result = calculate_sum(5, 3) print(f"התוצאה היא: {result}")
# רשימות (Lists) fruits = ["תפוח", "בננה", "תפוז"] fruits.append("אבטיח") for fruit in fruits: print(f"אני אוהב {fruit}") # מילון (Dictionary) person = { "name": "שרה", "age": 30, "city": "תל אביב" } print(person["name"])

מבני נתונים בסיסיים

📋 רשימות (Lists)

אוסף מסודר של פריטים שניתן לשנות

numbers = [1, 2, 3, 4, 5] numbers.append(6)

📖 מילונים (Dictionaries)

זוגות מפתח-ערך למידע מובנה

🔒 קבוצות (Sets)

אוסף של פריטים ייחודיים ללא סדר

colors = {"אדום", "כחול"} colors.add("ירוק")
